## 2. Using SQL (if you store transactions in a relational database)

```sql
SELECT
    account_id,
    transaction_id,
    transaction_date,
    payee,
    amount
FROM
    transactions
WHERE
    transaction_date >= DATE_TRUNC('month', CURRENT_DATE)   -- this month
    AND amount <> 0                                        -- ignore zero‑value entries
ORDER BY
    ABS(amount) DESC
LIMIT 10;   -- returns the top 10 largest transactions
```

- **Explanation**:  
  - `ABS(amount)` gives the magnitude regardless of whether it’s a debit or credit.  
  - Adjust the `LIMIT` to return as many rows as you need.  
  - You can add `WHERE amount < -5000` if you only care about large debits.

## 3. Using Python (pandas)

```python
import pandas as pd

# Load your transaction data (CSV, database, etc.)
df = pd.read_csv('transactions.csv', parse_dates=['transaction_date'])

# Filter for this month

end   = start + pd.offsets.MonthEnd()
